Lights

basement show control

One room. One operator. One LAN. Select a scene; this station drives the fixtures. Built for a basement rig, not a touring console.

What this is

Lights is the house show-control computer. An operator selects a scene. The scene sequences DMX looks and WLED strips on the beat. There is no cloud, no login, and no spare console — if this machine is off, the room is dark.

Stations

Performance is live control: scene tiles, spacebar beats, deactivate, and Blackout.

Builder authors fixture looks, pairs them into a dmx_preset, stacks cue lists, then saves scenes.

The rig

Chauvet GigBAR 2 23CH · u1 ch 1–23
Keobin light bar 18CH · ch 24–41
WLED / LEDfx strips scene names
ILDA laser storage only · not live

How to run

  1. Build device presets per fixture.
  2. Pair GigBAR + Keobin into a look (dmx_preset).
  3. Order looks into cue lists. Same for WLED.
  4. Pair a DMX list with a WLED list → scene.
  5. Open Performance. Activate a scene. Spacebar is the beat until audio lands.

Standing orders

  1. One operator. This station is not a drink coaster.
  2. Blackout is the panic control. Use it when the room needs to go dark.
  3. The GigBAR has a laser. Do not stare into it. Do not point it at faces.
  4. This box talks unicast on universe 1. If the LAN dies, the looks die with it.
  5. Beats are still a tap. Until live audio is wired, the operator is the metronome.
